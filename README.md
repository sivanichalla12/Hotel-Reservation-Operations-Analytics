# 🏨 Hotel Reservation Operations Analytics | Power BI

## 📖 Project Overview
This project is an interactive **Power BI dashboard** developed to analyze hotel reservation operations and provide actionable business insights. The dashboard helps monitor booking demand, revenue performance, guest behavior, stay outcomes, room utilization, and operational efficiency across multiple hotel properties.

## 🎯 Objectives
- Analyze booking trends and seasonal demand.
- Evaluate hotel revenue performance.
- Understand guest booking behavior and loyalty.
- Monitor stay status and operational outcomes.
- Analyze room type demand and booking channels.
- Provide data-driven insights and business recommendations.

## 🛠️ Tools & Technologies
- **Power BI Desktop**
- **Power Query**
- **DAX (Data Analysis Expressions)**
- **Data Modeling**
- **CSV Datasets**

## 📊 Dashboard Features
- Interactive KPI Cards
- Monthly Booking Trend Analysis
- Revenue by Hotel
- Stay Status Distribution
- Bookings by Channel
- Room Type Analysis
- Guest Loyalty Analysis
- Interactive Slicers for Dynamic Filtering

## 📌 Key KPIs
- Total Revenue
- Total Bookings
- Total Guests
- Total Stays
- Average Booking Value
- Total Nights Stayed

## 💡 Key Insights
- Generated **45.82M** in total revenue from approximately **3,000 bookings**.
- Booking demand peaked during **May**, indicating seasonal travel patterns.
- **Standard rooms** were the most requested room type.
- The **Website** was the leading booking channel.
- **StayPoint Mumbai Grand** and **StayPoint Mumbai Residency** generated the highest revenue.
- Most stays were successfully completed, while cancellations and no-shows highlight opportunities for operational improvement.

## 🚀 Business Recommendations
- Strengthen online booking channels through website optimization.
- Reduce cancellations and no-shows using automated booking reminders.
- Improve occupancy of premium room categories with targeted promotions.
- Expand the loyalty program to increase repeat bookings.
- Apply successful strategies from top-performing hotels across other properties.

## ✅ Conclusion
This project demonstrates end-to-end Business Intelligence skills, including data cleaning, data modeling, DAX measure creation, dashboard design, KPI development, and business insight generation to support data-driven decision-making in hotel operations.
